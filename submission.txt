To reproduce all destinations:
1. Start a PostgreSQL database (docker compose up -d --wait is provided).
2. Set DATABASE_URL to a writable PostgreSQL connection URL.
3. Set SPREADSHEET_ID to the review ID or a spreadsheet you control.
4. Set GOOGLE_APPLICATION_CREDENTIALS to the absolute path of google-sheets-api.json.
5. Share the spreadsheet with the service account client_email as editor; enable the Sheets API.
6. Run python main.py --submission.

PowerShell syntax: $env:VARIABLE_NAME = 'value'
POSIX shell syntax: export VARIABLE_NAME='value'
The application does not automatically read .env files.
